📦 Stock & Asset Management System
📋 Project Overview

This is a Stock and Asset Management System built with React.
The application helps organizations efficiently manage office assets such as laptops, desktops, servers, and other equipment.

Key features include:

Asset creation, editing, and deletion

Category-based asset management

Search and filter functionality

Dark mode support

Excel export

Local storage persistence

Responsive UI with modern glassmorphism styling

⚙️ Getting Started

Follow these steps to run the project locally using Visual Studio Code.

✅ Prerequisites

Make sure you have the following installed:

- Node.js (v16 or later recommended)

- npm or yarn

- Git

Visual Studio Code

🚀 Installation & Running the Project
1️⃣ Clone the Repository
git clone https://github.com/your-username/stock-management.git

2️⃣ Open the Project in VS Code
cd stock-management
code .

3️⃣ Install Dependencies
npm install


or

yarn install

4️⃣ Start the Development Server
npm start


or

yarn start

5️⃣ Open in Browser

Once started, the app will run at:

http://localhost:3000
